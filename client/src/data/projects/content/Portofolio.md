### Description 
This project is simply this webpage. It is written in Typescript with the React framework (Vite). It was orginally just HTML, but at my current work we are using react for some internal frontends, so i decided to use it for this project.

### Goal
This project is just to function as a hub for my projects, such that i can easily show what i have made, incase someone is interested. Its also the main way i tend to navigate alot of my projects

#### Design goals
- Make it datadriven, ie. components contain to state or data, they are just functions to draw elements, what they draw depends on their input. Pages is the home for reuniting components with their data.

### Reflection
The datadriven approach is extremly easy to work with, and makes writing a page extremely trivial. I will consider this alot more going forward.
